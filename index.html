¿Qué sabe una web sobre ti?

Sin aceptar ninguna cookie, una web puede construir un perfil detallado de tu dispositivo y comportamiento.

🖥️
Hardware
Núcleos CPU, RAM aproximada, puntos táctiles, GPU y arquitectura del procesador.
navigator.hardwareConcurrency
🌐
Navegador
User-Agent, idiomas, plugins instalados, soporte de APIs, Do Not Track.
navigator.userAgent
🖼️
Canvas Fingerprint
Cada GPU renderiza píxeles de forma distinta. Ese hash te identifica sin cookies.
Canvas 2D API
🎵
Audio Fingerprint
El motor de audio genera señales únicas que crean un identificador estable del sistema.
OfflineAudioContext
📡
Red
Tipo de conexión, velocidad estimada, latencia RTT y estado del modo ahorro de datos.
NetworkInformation API
🔒
Permisos
Estado de cámara, micrófono, geolocalización y notificaciones — sin pedirlos.
Permissions API
🔡
Fuentes instaladas
Midiendo el renderizado de texto en canvas se detectan las fuentes de tu sistema.
Canvas metrics
🖱️
Comportamiento
Clicks, movimientos del ratón, scroll máximo, tiempo en página y cambios de pestaña.
Event listeners

Sobre el proyecto

Análisis de Exposición de Datos y Hardening en Infraestructuras Web

El objetivo de este TFG es demostrar, de forma didáctica y transparente, la cantidad de información que un usuario cede durante la navegación web — incluso sin aceptar cookies tradicionales.

Integra administración de sistemas, seguridad, redes y desarrollo web: desde el diseño de red en Packet Tracer hasta el despliegue automatizado con CI/CD en GitHub Pages y Cloudflare Workers.

Fase 3 · Tracking y fingerprinting Completada
